# 산도장 — 함께 쓰는 백패킹 기록장

휴대폰 홈 화면에 추가해서 쓰는 웹앱이에요. 정복한 산 지도, 정상·야영지 도착 체크(인증), 인증샷, 산행 준비물·공동 장비 나눠 들기를 지인들과 함께 써요.

- 앱 주소: https://friese8807.github.io/sandojang/  (예시 화면: 주소 끝에 `#demo`)
- 초대 주소: https://friese8807.github.io/sandojang/?join

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 앱 화면 전부 (파일 하나) |
| `Code.gs` | 서버(구글 Apps Script). main 에 올리면 자동으로 배포돼요 |
| `.github/workflows/deploy-server.yml` | 서버 자동 배포 |
| `server-ids.env` | 자동 배포가 만든 서버 번호 (처음 배포 뒤 생겨요) |
| `version.txt`, `sw.js`, `manifest.webmanifest` | 새 버전 자동 반영, 오프라인, 홈 화면 앱 설정 |
| `icon-*.png`, `icon.svg` | 홈 화면 아이콘 |

## 개인 정보

- 저장소는 공개예요. 사람 이름·사진·기록은 코드에 없고, 서버의 구글 시트·드라이브에만 있어요.
- 도착 체크는 휴대폰이 '인증됨/기록만'을 판정하고, 서버에는 어느 산·인증 여부·거리(100m 단위)만 보내요. 내 좌표는 서버로 가지 않아요.
- 사진은 공유하지 않은 드라이브 폴더에 있고, 로그인한 사람에게만 서버를 거쳐 보여 줘요.

## 100대 명산 목록 넣기

1. 공공데이터포털에서 '한국등산트레킹지원센터 100대명산' API 활용신청
2. 서버 편집기 → 프로젝트 설정 → 스크립트 속성에 `DATA_GO_KR_KEY` (인증키) 추가
3. 편집기에서 `debugTop100()` 실행 → 응답 확인 → `importTop100()` 실행
